# Git Workflow Rules

1. Always commit and push changes directly to GitHub on `main` without asking for permission.
2. Commit message format:
   - 3 to 8 words.
   - Describe only what was actually changed.
   - Do NOT use conventional commit prefixes (no `feat:`, `fix:`, `chore:`, `refactor:`, `style:`, `docs:`, `test:`, `perf:`, `build:`, `ci:`).
   - No AI, Antigravity, ChatGPT, or Gemini references in commit messages.
   - No emojis.
   - Keep messages clean, capitalized, and natural.
